# Activity_Insight
Проект Activity Insight представляет собой настольное приложение для анализа пользовательской активности. 

Система отслеживает, какие программы использует пользователь, определяет периоды продуктивной работы и отдыха, сохраняет статистику локально и визуализирует её в удобном интерфейсе. 

В отличие от существующих решений, проект делает упор на приватность, офлайн-работу и возможности классификации приложений.

Данное приложение использует фреймворк Qt (https://www.qt.io). Qt распространяется под лицензией GNU GPL v3. (This application uses Qt framework (https://www.qt.io). Qt is licensed under the GNU GPL v3.)
